# rules — Κανόνες, αποφάσεις και σχεδιασμός μηχανισμού

Το επίπεδο **κανόνων** της αυτοματοποίησης: ποια άρθρα μπαίνουν, ποια πεδία γίνονται
παράμετροι, ποιες είναι οι εγκεκριμένες προεπιλογές.

> **Κατάσταση: σε εξέλιξη.** Καμία απόφαση δεν είναι εγκεκριμένη. Τα αρχεία είναι
> προς επεξεργασία από τον Επιχειρησιακό Χώρο Προμηθειών.

## Περιεχόμενα

| Αρχείο | Τι είναι |
|---|---|
| `00_DESIGN_Automation_Engine.md` | Ο μηχανισμός: 4 μητρώα, ροή 8 σταδίων, ταξινομία κανόνων, ρόλος του HTML |
| `01_ARTICLE_RULES_A/B/C.md` | Μητρώο άρθρων ανά πρότυπο — ζώνη, tokens, conditionals, ιδιοκτήτης |
| `01_CHECKLIST_A/B/C_*.xlsx` | Αποφάσεις **TOKENIZE / LOCK / DROP** ανά πεδίο. Στήλη `ΑΠΟΦΑΣΗ` προς συμπλήρωση |
| `02_REGISTER_Template_Comments.xlsx` | Τα 101 σχόλια των προτύπων, δομημένα και διασταυρωμένα με το data model |
| `03_TERMS_LIBRARY_prefilled.xlsx` | Βιβλιοθήκη Προτύπων Όρων, προσυμπληρωμένη από τεκμήρια |
| `eisigitika/` | Data model εισηγητικών + τα 3 δείγματα με σημειωμένα πεδία (πράσινα tokens) |

## Ευρήματα που είναι σφάλματα, όχι αποφάσεις

1. **Πρότυπο Α** — 6 tokens του πίνακα οροσήμων είναι **σπασμένα** σε δύο παραγράφους
   (`{{commercials.` + αλλαγή παραγράφου + `implementation_milestones.0.amount}}`).
   Δεν λειτουργούν σήμερα.
2. **Πρότυπο Α** — το `commercials.total_price` δεν υπάρχει πουθενά· το άρθρο 12
   (Όροι Πληρωμής, 32 παράγραφοι) έχει μηδέν tokens.
3. **Πρότυπο Α** — διπλή αρίθμηση «Άρθρο 23».
4. **Πρότυπο Γ** — το άρθρο 15.6 περιέχει διεύθυνση τρίτης εταιρείας
   («Αθήνα, Λ. Μεσογείων 2-4»).
5. **Data model** — διορθώθηκε ελληνικό όμικρον σε λατινικό token
   (`penalties.severity_rates_resolution[]`).

## Ανοικτά ερωτήματα

Συγκεντρωμένα στα `01_ARTICLE_RULES_*.md` §5–6 και φιλτράρσιμα στο
`02_REGISTER_Template_Comments.xlsx` (στήλη `Είδος` = ΕΡΩΤΗΜΑ).

## Κρίσιμη εξάρτηση

Το **82% των πεδίων της σύμβασης** δεν προκύπτει από το εισηγητικό — είναι πολιτική της
Τράπεζας. Χωρίς τη **Βιβλιοθήκη Προτύπων Όρων** συμπληρωμένη, η αυτοματοποίηση κλειδώνει
στο ~18%. Είναι οργανωτική εξάρτηση, όχι τεχνική.
