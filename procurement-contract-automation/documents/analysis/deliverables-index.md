## Πώς συνδέονται

```
DATA_MODEL.xlsx          ← αναγνώσιμο από ανθρώπους (Νομική, Προμήθειες)
      ↕  1:1 αντιστοίχιση
schema/*.json            ← αναγνώσιμο από λογισμικό (επικύρωση, φόρμες, integrations)
      ↓  τροφοδοτεί
templates_clean/*.docx   ← {{tokens}} που αντιστοιχούν στα πεδία του schema
      ↓  παράγει
Τελικό έγγραφο σύμβασης
```

Η στήλη **«Πεδίο (token)»** του Excel είναι ακριβώς το `{{token}}` μέσα στα πρότυπα και ακριβώς η διαδρομή στο JSON Schema. Ένα όνομα, τρεις χρήσεις.

## Τι χρειάζεται πριν το επόμενο βήμα

**Blocking:**
1. Τα **Παραρτήματα** (κανένα δεν έχουμε) — εκεί ζει ο μεγαλύτερος όγκος μεταβλητών (Q-01)
2. Πρότυπο **Πίνακα Τιμών** / μορφή Οικονομικής Προσφοράς (Q-02)
3. **3–5 υπογεγραμμένες συμβάσεις ανά κατηγορία** αντί για μία (Q-03) — αλλιώς δεν διακρίνεται ο σταθερός όρος από τη διαπραγματευμένη παρέκκλιση

**Αποφάσεις πολιτικής:** κατώφλι εγγυητικής (Q-06), προθεσμία πληρωμής 45 vs 60 ημέρες (Q-07), ποσοστά ποινικών ρητρών (Q-08), όριο ευθύνης (Q-09), πίνακας εξουσιοδοτήσεων υπογραφόντων (Q-10), συλλογή αντικλήτου (Q-11).

**Τεχνολογία:** αν η υλοποίηση γίνει σε Power Apps / Dataverse, το JSON Schema λειτουργεί ως προδιαγραφή· αν γίνει σε custom εφαρμογή ή document-assembly engine, χρησιμοποιείται απευθείας.

**Προτεινόμενο pilot:** Κατηγορία **D (Πρόσθετη Πράξη)** — μικρότερο έγγραφο, πλήρως δομημένο μοντέλο, μεγαλύτερος ετήσιος όγκος.
