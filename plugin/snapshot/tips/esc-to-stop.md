The single most important key in Claude Code is **Esc**.

When Claude is about to do something you don't want — modify the wrong file, run a destructive command, head down a wrong path — press **Esc** and it stops *right now*. You don't have to wait for it to finish; you don't have to control-C the terminal.

Use it freely:

- It looked confused mid-edit? Esc.
- It's running a long task you've changed your mind about? Esc.
- Your phone rang? Esc.

After you stop, you can correct ("no, what I meant was…") and continue. The session is intact.

**Esc Esc** (press it twice) clears the input box — the one you want when your half-written prompt has turned into a mess and you'd rather start the sentence again.

Stopping and undoing are different jobs, though. Esc halts what Claude is *about* to do; it doesn't reverse what's already done. When Claude has gone several steps wrong and you want to go back rather than forward, the command is **`/rewind`** — see the rewind-dont-repair tip.
