Claude Code ships with a guided tour of itself. Almost nobody runs it.

Type this in any session:

```
/powerup
```

Claude Code describes it as *"Discover Claude Code features through quick interactive lessons"* — short, hands-on walkthroughs of the features that don't announce themselves. It's the same idea as this hub, built into the tool.

**When to reach for it:** your first week, and again after a month. The second run lands differently, because by then you've hit the problems the lessons solve.

Two more built-ins worth knowing on day one:

- **`/help`** — shows every available command. When you can't remember whether a thing exists, this is faster than searching.
- **`/keybindings`** — opens your keyboard shortcuts file, which is also the honest list of what every key actually does in *your* version.

That last one matters more than it sounds. Keyboard shortcuts drift between versions, and half the shortcut lists floating around online are wrong. `/keybindings` is the version you're actually running.
